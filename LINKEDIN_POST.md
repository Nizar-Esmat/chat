# LinkedIn Post - NizarChat

🚀 Excited to share my latest project: NizarChat - A Real-Time Chat Application! 💬

I've built a modern, full-stack chat application using the MERN stack that brings instant messaging to life. Here's what makes it special:

✨ Key Features:
• Real-time messaging powered by Socket.IO
• Secure JWT authentication
• Live online status indicators
• Image sharing with Cloudinary
• Sound notifications & keyboard effects
• Beautiful UI with Tailwind CSS
• Rate limiting & bot protection with Arcjet

🛠️ Tech Stack:
Frontend: React, Zustand, Socket.IO Client, Vite
Backend: Node.js, Express, MongoDB, Socket.IO
Services: Cloudinary, Resend, Arcjet

This project challenged me to master real-time communication, state management, and secure authentication - all while creating a seamless user experience.

💡 What I learned:
• WebSocket implementation for real-time features
• Centralized environment variable management
• Production-ready deployment strategies
• Security best practices with rate limiting

The app is fully functional with features like instant messaging, online status tracking, and image sharing - all with a modern, responsive design.
